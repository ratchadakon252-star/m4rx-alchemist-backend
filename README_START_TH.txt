THE ALCHEMIST NEXT — IMAGE FIRST (รุ่นทดลอง)
============================================

ติดตั้งง่ายบน Windows:
1. คลิกขวา ZIP > Extract All (ห้ามรันโปรแกรมจากภายใน ZIP)
2. ดับเบิลคลิก START_WINDOWS.bat
3. โปรแกรมจะเปิด http://127.0.0.1:8765 ในเบราว์เซอร์
4. ในเว็บ เปิด 'ตั้งค่าการเชื่อมต่อ / ทดสอบ Engine'
5. เลือก Gemini API หรือ OpenAI API แล้ววาง API Key > กดเชื่อม AI Vision ชั่วคราว
6. แนบภาพ XAUUSD H1/M15/M5 เลือก Mode แล้วกดวิเคราะห์

หากไม่มี API Key ให้กดทดลอง Python Core Engine ด้วยข้อมูลจำลองได้
Gemini Pro / ChatGPT Plus ไม่รวมสิทธิ์ API อัตโนมัติ

ข้อจำกัด: ภาพถูก AI วิเคราะห์แบบ Preview เท่านั้น; Python P4 Engine ไม่ได้รับ
native OHLC จากภาพและยังไม่ยืนยันความแม่นยำด้วยข้อมูลตลาดจริง
ห้ามใช้เป็นสัญญาณเทรดเงินจริง ไม่มีการส่งคำสั่งให้ Broker

ไฟล์ START_WINDOWS.bat จะค้างไว้เมื่อเกิดข้อผิดพลาด เพื่อให้เห็นข้อความ
อย่าปิดหน้าต่างสีดำระหว่างใช้งาน
