M4RX ALCHEMIST — GitHub Ready (ตัวเต็ม)

1) แตก ZIP ด้วย Extract All
2) เปิดโฟลเดอร์ที่แตก แล้วเลือกทั้งหมด Ctrl+A / Ctrl+C
3) GitHub Desktop → Clone repository `m4rx-alchemist-backend` (PRIVATE)
4) Repository → Show in Explorer → Ctrl+V วางทั้งหมด
5) GitHub Desktop → Commit to main → Push origin
6) ตรวจว่ามี app.py, Dockerfile, engine ในระดับ Root ของ GitHub
7) อ่านคู่มือเต็ม UPLOAD_GITHUB_RENDER_TH.md สำหรับต่อ Render

ห้ามอัปโหลดคีย์จริง, ไฟล์ .env, หรือสร้าง Repository แบบ Public โดยไม่ตรวจสิทธิ์เอกสารต้นฉบับ
